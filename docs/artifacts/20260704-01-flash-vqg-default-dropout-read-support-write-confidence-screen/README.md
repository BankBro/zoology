# 20260704-01-flash-vqg-default-dropout-read-support-write-confidence-screen

This artifact contains the closeout summaries for the default-dropout read-support/write-confidence screen.

Files:

- `final-summary.csv`: per-machine final validation metrics parsed from logs.
- `paired-summary.csv`: paired 2080ti vs 3090 comparison by variant.
- `source-manifest.csv`: lightweight raw evidence paths, mirror state, sizes, and sha256.
- `metadata.json`: run-level metadata, cache/init/batch checks, and closeout notes.

Large raw outputs, checkpoints, and full logs remain in the ignored experiment output directories listed in `source-manifest.csv`.
