### 增量 P3 / 全稿 P18. 跨 GPU Longer-MQAR: 优势集中在长度外推

状态: 已制作.

建议版式:

- 底部: 一条直接结论.

右侧信息:

1. 实验覆盖:
   - 2080 Ti 与 RTX 3090.
   - Flash/GDN, seeds 123/124/125.
   - `12/12` 个正式 4 epoch run.
2. 质量结果:
   - 训练端点 `1024×256`: Flash 不领先.
   - 四个长度外推切片: Flash 平均准确率均高于 GDN.
   - RTX 3090 四个外推切片均为 `3/3` seeds 领先.
3. 结论边界:
   - GDN 同 seed 跨 GPU 高度稳定.
   - Flash 的跨 GPU 变化主要受 seed124 影响.
   - 两张 GPU 上的相同 seed 不是独立重复, 分别按 `n=3` 统计, 不合并为 `n=6`.

底部结论:

> Flash 的优势来自训练长度之外的关联记忆保持, 但其训练轨迹对 seed 和 GPU 数值执行路径更敏感.

### 增量 P4 / 全稿 P19. 低精度实验: 长度外推优势保持, BF16 更具效率

状态: 已制作.

页面作用: 用一页同时交代低精度覆盖范围、质量结论、机制拆分和效率收益.

建议版式:

- 左侧约 68%: 直接复用 `matching-precision-last.png` 作为主图.
- 右侧约 32%: 四组关键数字.
- 底部: 一条面向下一阶段的结论.

右侧信息:

1. 实验覆盖:
   - 2080 Ti: FP32/FP16.
   - RTX 3090: FP32/FP16/BF16.
   - Flash/GDN × 3 seeds, `30/30` 个正式 4 epoch run.
2. 质量结论:
   - 四个外推切片中, Flash 在 `60/60` 个 matching dtype 配对中高于 GDN.
   - 训练端点仅为 `3/15`, 优势仍集中在长度外推.
3. 机制拆分:
   - 固定 checkpoint 改变 eval dtype, 最大 accuracy span 仅 `0.002328`.
   - 主要差异来自低精度训练形成的不同优化轨迹, 而不是低精度评估本身.
4. BF16 收益:
   - RTX 3090 Flash BF16 wall time 为 FP32 的 `0.862x`.
   - Peak allocated 显存约为 FP32 的 `0.819x`.

底部结论:

> FP16/BF16 未破坏 Flash 的长度外推优势; RTX 3090 BF16 已具备进入 300M 自然语言训练 smoke 的质量与效率依据.

### 增量 P5 / 全稿 P20. 下一步: 300M 自然语言训练与下游评估闭环

状态: 待制作.

页面作用: 将 MQAR 上的机制、效率与低精度可行性结论, 转化为下一阶段可执行的自然语言实验路线. 本页强调“先校准闭环, 再做公平主比较”, 不把 1B-token 结果包装为充分预训练后的通用能力排名.

建议标题:

> 下一步: 300M 自然语言训练与下游评估闭环

建议版式:

- 顶部条件条: `约 300M 参数`, `FineWeb-Edu 1B actual tokens`, `context 2048`, `last@1B`.
- 中部使用三阶段横向流程, 每个阶段只保留目标、模型和关键门槛.
- 底部用一条结论边界收束, 说明本轮回答的是早期学习效率与训练可行性.

中部三阶段流程:

```text
Phase 0: 评估栈校准
冻结数据/evaluator/prompt
随机模型 + 公开 anchor 校验
checkpoint 与 HF export 等价性
            ↓
Phase A: 1-seed 闭环
Flash-VQG + GDN + matched Transformer++
seed 42, milestone 子集, last@1B 全量核心任务
            ↓
Phase B: 三 seed 公平主比较
增加 Mamba-2
seeds 42/123/4321, paired analysis, contamination audit
```

首轮核心任务:

- FineWeb-Edu source-level held-out 与 WikiText-2: 训练分布内外的 NLL/PPL.
- LAMBADA: discourse、实体追踪与长程词汇预测.
- HellaSwag 与 PIQA: 事件常识和物理常识.
- BLiMP: 形式语法与语言结构.
- Final checkpoint 再补 WinoGrande、ARC-Easy 和 SciQ.

公平 baseline:

- P0 主表: `Flash-VQG + Gated DeltaNet + matched Transformer++`.
- P1 推荐: `Mamba-2` 通过 adapter 与 smoke 后加入三 seed 主比较.
- GPT-2 Medium、Cerebras-GPT、Pythia 和 SmolLM2 只作为 external pretrained references, 不进入同预算架构胜负统计.
- Mamba-3 与 Gated DeltaNet-2 属于后续 frontier 扩展, 不阻塞首轮自然语言闭环.

Go/no-go 门槛:

- Train/validation loss 稳定下降, 无持续 NaN/Inf 或异常 spike.
- Export 前后 logits/loss 在预注册容差内一致.
- WikiText/LAMBADA likelihood 有限且随训练改善.
- HellaSwag、PIQA、WinoGrande 或 BLiMP 中至少部分连续 likelihood 指标方向稳定.
- 三个 P0 架构完成相同数据、token 预算、resume、export 和 evaluation 闭环.

底部结论:

> 下一步先完成 Phase 0 与 Phase A, 验证自然语言训练和评估闭环; 通过后再扩展到三 seed、四模型的公平主比较.

结论边界:

- 1B-token 结果定位为“早期学习效率与自然语言训练可行性研究”.
- ARC-Challenge、MMLU 或长文本任务接近随机或 metric floor, 不能单独用于否定架构.
- MQAR 继续作为独立机制诊断, 不替代自然语言综合能力评估.
