\begin{frame}{长上下文模型真的“记住”了吗?}
  \centering
  \begin{minipage}{0.92\textwidth}
  \small
  长文档问答、代码理解、长对话都依赖前文信息。长上下文能力的关键不只是
  \textcolor{scured}{“能输入多长”}, 更重要的是: 后面能不能准确找回前面出现过的信息。

  \vskip0.32cm
  \begin{beamercolorbox}[sep=7pt,rounded=true,shadow=true,wd=\linewidth]{block body}
    \centering
    {\footnotesize\color{gray}Input: 前文写入若干键值绑定, 后文只给出查询键}\\[3pt]
    {\resizebox{0.94\linewidth}{!}{\ttfamily
      A\,4 \quad B\,3 \quad C\,6 \quad F\,1 \quad E\,2
      \quad \textcolor{scured}{\(\longrightarrow\)}
      \quad A\,? \quad C\,? \quad F\,? \quad E\,? \quad B\,?
    }}\\[5pt]
    {\footnotesize\color{gray}Output: 模型必须按查询顺序读出对应值}\\[3pt]
    {\Large\bfseries\color{scured}4,\;6,\;1,\;2,\;3}
  \end{beamercolorbox}

  \vskip0.30cm
  \begin{columns}[T,onlytextwidth]
    \begin{column}{0.48\linewidth}
      \begin{block}{形式上}
        \centering
        \vspace{0.12cm}
        记住前文的键值绑定
        \vspace{0.12cm}
      \end{block}
    \end{column}
    \begin{column}{0.48\linewidth}
      \begin{block}{本质上}
        \centering
        \vspace{0.12cm}
        在大量干扰信息中准确读出
        \vspace{0.12cm}
      \end{block}
    \end{column}
  \end{columns}

  \vskip0.12cm
  \begin{beamercolorbox}[sep=3pt,rounded=true,wd=\linewidth]{block body}
    \centering\small
    \textcolor{scured}{\bfseries MQAR (Multi-Query Associative Recall)}: 检验长上下文中的多查询关联回忆能力.\\[2pt]
    关键不是只读完整个上下文, 而是在大量干扰信息中保持并读出正确的键值绑定.
  \end{beamercolorbox}
  \end{minipage}
\end{frame}

\begin{frame}[t]{方法概览: Flash-VQRM}
  \centering
  \vspace{0.06cm}
  \begin{minipage}{0.92\textwidth}
  \small
  \setbeamerfont{block title}{size=\small}
  模型把一次状态读写拆成三部分: \textcolor{scured}{分槽统计}, \textcolor{scured}{残差校正}, 和 \textcolor{scured}{顶层融合}.

  \vskip0.06cm
  \begin{columns}[T,onlytextwidth]
    \begin{column}{0.64\linewidth}
      \centering
      \includegraphics[width=1.14\linewidth,height=5.55cm,keepaspectratio]{20260523/p10/model-structure.jpg}
    \end{column}

    \begin{column}{0.34\linewidth}
      \vskip-0.16cm
      \begin{block}{Coarse memory: 先分槽统计}
        \footnotesize
        \vspace{0.04cm}
        VQ 将相近键路由到同一记忆槽, coarse memory 保存槽级粗粒度历史.
        \vspace{0.04cm}
      \end{block}

      \vskip0.03cm
      \begin{block}{Residual memory: 再校正误差}
        \footnotesize
        \vspace{0.04cm}
        residual memory 记录槽内细节偏差, 用于补偿粗粒度读出的误差.
        \vspace{0.04cm}
      \end{block}

      \vskip0.03cm
      \begin{block}{Aggregation: 融合三路输出}
        \footnotesize
        \vspace{0.04cm}
        顶层聚合把 \(O_{local}\), \(O_{coarse}\), \(O_{res}\) 合成为最终输出 \(O_t\).
        \vspace{0.04cm}
      \end{block}
    \end{column}
  \end{columns}

  \vskip0.04cm
  \begin{beamercolorbox}[sep=3pt,rounded=true,wd=\linewidth]{block body}
    \centering\small
    \textcolor{scured}{\bfseries 关键流程: VQ 分槽组织历史, residual memory 负责槽内误差补偿.}
  \end{beamercolorbox}
  \end{minipage}
\end{frame}
